# レジデント勤務表（長崎医療センター 総合診療科）

ブラウザだけで動く勤務表アプリです。休日当番 Roster（duty-roster）と同じ Firebase プロジェクト・同じ Google カレンダー連携を使います。

- 勤務表：assift と同じ「氏名 × 日付」のグリッド。各自が自分の行に ✖ と病院指定の勤務（当直・準夜・夜間初期・外サポ）を入れる、管理者はセルをタップして割当
- 週末当番：3か月分の金土日ブロック。①（みどり兼任・大村在住）②（①と別チーム）を自動下書き → 手直し
- 平日当番：月〜木 1日1人 と 中澤（月曜・外来チーム）を自動下書き
- 祝日・連休：祝日当番①②と、GW・SW・年末年始（別枠）の週末を日ごとに調整
- 集計：年度（4〜3月）の回数
- Excel 出力：勤務表シート＋当番一覧シート＋「NMC当番シフト」形式（日付／曜日／研修医／担当／バックアップ）のシート。研修医・バックアップ列は手入力
- カレンダー同期：1日1イベントで共有カレンダーへ

## 公開手順（GitHub の画面だけで完了）

1. GitHub 右上の「＋」→「New repository」。Repository name は `resident-roster`、Public のまま「Create repository」
2. 「uploading an existing file」のリンク（または Add file → Upload files）を開き、`index.html` を1つドラッグ →「Commit changes」
3. 同じ手順で `app.js`、`config.js`、`README.md` を1つずつアップロード
4. リポジトリの「Settings」→ 左メニュー「Pages」→ Source を「Deploy from a branch」、Branch を「main」「/(root)」にして「Save」
5. 1〜2分後に https://takahiromori19800720-boop.github.io/resident-roster/ が開きます

ファイルを更新するときは duty-roster と同じく「ファイルを開く → ⋯ → Delete file → Commit」してから「Add file → Upload files」で1つずつ上げ直すのが確実です。更新後はハードリロード（Cmd+Shift+R）が必要です。

## 組み込んであるルール

- 週末当番①②は金土日を通しで同じ2人。①はみどり兼任（大村在住者のみ）、②は①と別チーム
- 平日当番は月〜木1日1人。外来チーム、スタッフ枠リーダー（氏名欄の「L」）は免除
- 当直を入れると翌日は自動で「明け」になり、その日は平日当番なし
- 木曜当直の人はその週の週末当番なし（金曜の申し送りのため）
- 外サポ・夜間初期・準夜は翌日も通常勤務（翌日の当番は可）
- 中澤（毎週月曜）は外来チームから。浦上（第2土日）は外来チームに限らず全員で年間均等（年度回数の少ない人から）。記念（第1土AM）は希望者から。記念は週末当番と重複しない
- マイ予定で何も入力していない人は全日「○ 可」として扱われる。各自が「この月の入力を完了する」を押すと、管理者の勤務表に未入力者が表示される
- 祝日①も みどり兼任（大村在住者）。GW・SW・年末年始は別枠として自動判定し、日ごとに調整
- 2週連続の週末当番は黄色の注意（割当自体は可能）
- GW・年末年始の平日は平日当番の自動下書き対象外。「祝日・連休」画面で個別に決める
- 締切（前月15日、月ごとに「提出状況」で変更可）を過ぎるとレジデントはマイ予定を変更できず、管理者だけが変更できる
- PIN は config.js の requirePin で範囲を切り替え（"admin"=管理者のみ／"all"=全員）。試験運用中は管理者のみ

## 初回にやること

1. 自分（森）を選び、初回はPIN（数字4〜6桁）を設定してログイン（管理者）
2. 各レジデントは初回ログイン時に「自分の設定」で希望する外勤先（浦上・みどり・上田記念）にチェック。管理者は「レジデント」タブで在籍期間などを設定
3. 「勤務表」タブで氏名欄のチーム（A/B/C…）を設定。翌月以降は「チームを前月からコピー」が使えます
4. 管理者が「外来を範囲入力」で各人の外来期間を入れる
5. レジデントに URL を LINE で共有 → 当直表が出たら各自が自分の行に 「マイ予定」タブで、1. 外来期間 → 2. 当直・夜間初期・準夜 → 3. 残った日の希望（○可／◎とても希望／✖できない）の順に入力（締切は前月15日）

## 毎月の作成順

1. 祝日・連休（別枠）を先に決める
2. 週末当番タブで3か月分を「空き枠を自動下書き」→ 手直し（記念・浦上もここ）
3. 平日当番タブで「空き日を自動下書き」→ 手直し
4. 勤務表タブで違反（赤枠）・注意（黄枠）を確認 →「この月を確定」
5. 「この月を確定」を押すと共有カレンダー（NMC レジデント当番）へ自動で同期。「当番シフト Excel」で NMC当番シフト.xlsx と同じ列（日付・曜日・研修医・担当・バックアップ、土曜青・日祝赤）を出力。割当を直したら「カレンダー同期」で再同期

## 管理者の引き継ぎ

「レジデント」タブ下部の「管理者権限の移譲」で、労務担当のレジデントを管理者に追加できます。管理者は複数人にでき、引き継ぎが終わったら前任者の権限を「解除」します（最後の1人は解除できません）。ログインは名前を選んで本人のPIN（数字4〜6桁、初回に自分で設定）を入力します。PINを忘れた人は管理者が「レジデント」→「編集」→「PINをリセット」で消し、次回ログイン時に再設定してもらいます。

## 設定（config.js）

- `rules.midoriSlot`: みどり兼任が入る週末スロット。assift の凡例に合わせて `"w1"`（週末①）。②にする場合は `"w2"`
- `rules.holidaySlots`: 祝日当番の人数（1 か 2）
- `rules.deadlineDay`: 前月の締切日（15）
- `google.calendarId`: 同期先カレンダー。レジデント専用カレンダーにするならここを変更

## うまく動かないとき

- 読み込み中のまま止まる：Firebase コンソール → Firestore Database → ルール が `allow read, write: if request.auth != null` か `if true` になっているか確認（30日で期限切れになるテストモードに注意）
- カレンダー同期で「unauthorized origin」：Google Cloud コンソール → 認証情報 → OAuth クライアント に `https://takahiromori19800720-boop.github.io` が承認済み JavaScript 生成元として入っているか確認（duty-roster と同じなので通常は不要）
- Firestore のデータは `rr_staff` と `rr_months` コレクションに入ります（duty-roster の `staff` などとは別）
